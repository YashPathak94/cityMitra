# CityMitra social media kit

Everything here is copy-paste content for you to use when creating the
accounts — account creation itself needs a human (phone/email OTP,
CAPTCHA), so that part can't be automated. Once accounts exist, see
"Real automation" at the bottom for how to actually get daily posts without
manually posting each one.

itself a small SEO/trust signal (it's what "sameAs" in structured data
points at, and what people expect when they search your brand elsewhere).

## Profile links

Use `https://ctmitra.com` everywhere a single link is allowed. Instagram
only allows one bio link — if you want to rotate which page it points to
(a specific blog post, /offers, /travel-plan), a free "link in bio" tool
(Linktree, or just a `/links` page on the site itself) solves that; not

## Caption formula per platform

Use this pattern for every new blog post — swap in the post's title,
one-line hook, and link.

**Instagram** (caption + hashtags, casual, 1 emoji per line max):
```
[One-line hook, not the title verbatim] 👇

[1-2 sentences expanding the value, in plain language]

Read the full guide → link in bio

#IndianCities #CityGuide #TravelIndia #[CityName] #ctmitra
```

**X** (short, direct, link inline):
```
[Hook in under 200 characters]

[link]

#TravelIndia #[relevant tag]
```

**Facebook** (slightly longer, conversational, link inline — Facebook
unfurls the OG card automatically so don't repeat the title):
```
[2-3 sentence hook — can be a mini-story or a direct tip]

[link]
```

**LinkedIn** (professional framing — talk about the product/feature angle,
not just the destination):
```
[Opening line framing the problem]

[2-3 sentences on how CityMitra solves it — feature-focused]

Read more: [link]

#ProductUpdate #TravelTech #India
```

## Real automation (this is the actual "daily posting" solution)

I can't post to these platforms directly — no such tool exists in this
environment, and there's no way around the human account-creation step
either. But once the accounts above exist, wire them to the site's RSS
feed and posting becomes genuinely automatic, no manual work per post:

**Feed URL:** `https://ctmitra.com/blog/rss.xml`

1. **Buffer (free tier, easiest)** — Buffer → Create → "RSS" as a content
   source → paste the feed URL → connect your Instagram/Facebook/X/LinkedIn
   accounts → set posting schedule (e.g. "post 1 item/day"). Buffer
   auto-drafts a caption from the post title + excerpt; edit before it goes
   out if you want the hand-written captions above instead.
2. **Zapier — "RSS by Zapier" trigger** → "New Item in Feed" → action:
   "Create Tweet" / "Create Page Post" / "Share Update" (per platform).
   Free tier covers a handful of zaps at low volume.
3. **IFTTT** — similar RSS-trigger applets, one per platform.
4. **Meta Business Suite** (Instagram + Facebook only, native, free) — has
   its own post scheduler; doesn't read RSS automatically, but you can
   batch-schedule a week of posts in ten minutes using the captions above.

Any of these turns "daily blog → daily social post" into a one-time,
10-minute setup instead of a recurring manual task — which is the actual
automation this request was asking for.
