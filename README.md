# CityMitra

CityMitra is a 3D, AI-assisted city discovery website for quickly finding trusted shops, markets, hospitals, malls, eateries, repair points, sightseeing areas, and service destinations across Indian cities.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Enable AI answers

Create `.env.local`:

```bash
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-5-mini
```

Without an API key, the chat uses a local demo response so the site remains previewable.
